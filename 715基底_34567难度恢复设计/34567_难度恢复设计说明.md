# 第3—7关难度恢复设计（715基底）

日期：2026-11-18。状态：五关离线设计候选，均完成独立联合唯一性复核；尚未实机验收本批新卡面。用户已实机验收的是715基底。

本轮只产出设计，不修改运行时Lua，不导出716或其他新存档。五关墙、门、家具、人物和原答案均保留。全部人物卡为单句；所有线索在正常求解中一直参与，假话以逻辑否定约束参与，只有身份规则按条件调用。

五关不是同一水平：3作为较轻入口；4侧重真假判断、完整传播；5增加联动广度与传播链；6增加大盘面分类讨论；7综合身份、容量与更深分类。这个排序是设计定位，不是玩家计时验证后的心理难度排名。第4关位置试探由1降到0是有意取舍，换来更完整的纯演绎链和更大的矛盾联动，不声称所有指标都提升。

## 2. 三种提议如何落地

- **弱化与强化重整**：不添加卡位，把信息分散到人物关系、家具资格、行列排他与既有计数，再由交叉约束恢复定位。逐卡集合比较表明本批替换都是“交叉重整”，不是严格蕴含关系上的单向弱化或强化，不能把这些操作宣传成已证明的严格弱化—强化循环。
- **可推导前置条件**：设计中设置“先收窄一组位置、再恢复某人位置”或“先排除全真身份、再求假话分支”等关键中间结论。每个结论都有非空前提的蕴含见证；没有新增必须按顺序读卡的规则。
- **难度标准**：沿用本地标准对传播、试位、矛盾卡组、单卡定位、提示范围、语义贡献的区分；身份与真假验收采用715修正规则，旧教学特判与撤卡算法不参与验收。

所谓门槛是设计路线中的中间事实，不是对一切可能人类解法的必经性定理。子集蕴含实验仅作诊断，正式求解从不撤下线索。

## 3. 指标定义与适用边界

1. 所有身份都从未知开始枚举；不读取预设答案或盗窃者字段筛身份。候选搜索允许围绕已验收答案设计，唯一性验证完成后才与该答案比对。
2. 同步传播一轮包括单卡资格、双人关系弧一致、两两行列排他、所有大小的行/列Hall成组排除，以及唯一占用/计数约束的支持检查。每轮都以上轮候选为输入。轮数不是人类步数，停滞时更少轮数也可能更难。
3. **位置分类讨论深度是固定已成立真假分支后、人数规则前的指标**，不包含从零推导身份的成本。传播停滞后选择任意一个人物，把其所有候选位置分支，递归取最坏深度；遍历人物选择取最小值，本轮最多测至2层。
4. 终止条件除显式矛盾外，还允许对剩余候选做完整行列匹配：如果无匹配则矛盾；若所有匹配都已满足全部该分支口供，则认为线索阶段已完成，即使仍有多个等待人数规则的完整盘面。这比只做局部传播更强，已计入声明的操作集。
5. 深度0/1/2是该操作集的实测结果，不是所有人类解法的下界。允许跨卡合并、预先建立更强约束表，或身份入口已证明后提前使用人数规则，可能缩短路线。
6. 最小矛盾卡数：基础摆位与既有通用线索固定为真，找最少几张人物卡同时为真就无解。它衡量矛盾联动宽度，不等于推理步数。第7关全真可满足，故此指标不适用。
7. 浅蓝范围只反映显示语义，不把高亮总格数直接换算为难度。关系卡不新增静态提示；所有单卡独立使用时，每个人物仍至少2个可能位置。

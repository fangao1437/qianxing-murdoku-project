## 一 一句话

**午后三点的茶会少了一点光。魔法师独坐月窗，五位客人各执一词 —— 唯有猫的牌，在说谎。**

## 二 设计原点：两张「魔法师」

### 2.1 《月谕圣牌·一·魔法师》原文

> 意志如甘甜的茶水般流涌，
> 现实因兴致与闲暇而被塑造。
> 杯盏、羽毛笔、餐刀与装着甜点的圆盘，
> 小小的秘仪，调和的四质，
> 令人怀念的，午后的喧闹。
>
> 你说：万物皆备于我，
> 但归根结底，
> 那一个顷刻的欢笑与「魔法」，
> 也不过是无尽空无中
> 凝聚而成的一点光。

### 2.2 塔罗牌《魔术师》的符号

塔罗大阿卡那第一张「魔术师」（The Magician）右手举杖指天、左手按地，桌上摆放**圣杯、宝剑、权杖、星币**四器，头顶无限符号，周围玫瑰与百合 —— 象征"意志、创造、四元素俱备"；逆位则意味着**幻术、欺瞒、潜力被误用**。他是**杂耍者与骗术师**的原型：一个把所有道具都摆在台面上，却仍能让你看错的人。

### 2.3 两张牌的共同处境

- 同一个母题：**一个人、一张桌子、四件小器物、一场被你注视的"魔法"**。
- 同一个隐喻：**"万物皆备于我"的从容，与"一点光"的脆弱** —— 魔法师能调停四质，却留不住一个午后。
- 同一个危险：**魔术师的另一面是"说谎的人"**。台面上的四件道具是真的，台上的人却可能是假的。

### 2.4 转译表（牌 → 关卡）

| 牌上的文本 / 符号 | 关卡里的对应物 |
|---|---|
| 意志如甘甜的茶水般流涌 | 茶壶与茶；「一点光」靠茶水保温 |
| 现实因兴致与闲暇而被塑造 | 钟表匠把怀表停在三点 —— 这个午后是被"塑造"出来的 |
| 杯盏、羽毛笔、餐刀、甜点圆盘 | 四位客人各执一器：A 司茶女仆（杯盏）· B 午后诗人（羽毛笔）· C 甜点师（餐刀）· D 钟表匠（圆盘/怀表） |
| 小小的秘仪，调和的四质 | 四个房间 = 四质；四件器物 = 四元素；茶会本身 = 小小的秘仪 |
| 令人怀念的，午后的喧闹 | 玩家要摆出的六人座次，就是"午后喧闹"的复原 |
| 你说：万物皆备于我 | 魔法师的口头禅；也是他的盲点：他备齐了万物，却没算到一只猫 |
| 一个顷刻的欢笑与魔法 = 无尽空无中凝聚的一点光 | 被偷走的「一点光」；也是牌面之外那片"空无"（失败的结局：卡面褪成空白） |
| 塔罗·桌上四器 | 同上四元素；四件器物在四个房间里各据一方 |
| 塔罗·无限符号 | 钟表匠的怀表：首尾相接的午后循环 |
| 塔罗·指天指地（as above, so below） | 月窗（天上之月）与茶桌（地上之器）的上下呼应；也是卡框上下两端的菱形饰 |
| 塔罗·杂耍者 / 逆位·欺瞒 | **猫的牌**：一句假话；"主谋"以捣乱的形态混在客人中间 |

## 三 故事：月谕茶会

**舞台**：一张从牌堆里抽出的「月谕圣牌·一·魔法师」。牌面展开的一瞬，画里的午后茶会活了过来 —— 银白尖拱的卡框是天空，玫瑰与荆棘是墙，长桌上的茶还冒着热气。

**被偷走的东西**：不是财物，是「一点光」—— 那团在茶壶上方悬浮、让整个午后得以存在的小小暖光。卡牌文本说，一切欢笑与「魔法」都只是"无尽空无中凝聚而成的一点光"；现在，这一点光不见了。没有它，茶水会凉，玫瑰会褪色，牌面会一点点变回空白。

**受害者**：魔法师。午后三点，他独自坐在月窗廊，背对长桌看着月亮 —— 他以为一切"皆备于我"，所以没有回头。等他回头时，光已经不见了。

**五位客人**（五名嫌疑人）：
- 司茶女仆说：诗人一下午都没离开过羽毛笔，她给他续茶时看得清楚。
- 午后诗人说：甜点师守在蛋糕架旁，第七块蛋糕她一直没切。
- 甜点师说：钟表匠离他的怀表只有一步，三点被他停住了。
- 钟表匠说：司茶女仆从三点起就守在茶壶边，一步也没走开。
- 猫说：它一下午都趴在软垫上，哪儿也没去，尾巴都没动过。

**主谋**：猫「墨」。它没有四质、没有席位，却总在桌边。它偷走「一点光」，不是为了财，是因为那是整个茶会里唯一会动、会暖、会滚来滚去的东西 —— 它想把它藏进自己的尾巴里，让午后永远不结束。它甚至不觉得自己在"偷"：**猫只是把光拨到了桌子底下，像拨一颗毛线球。**

> 为什么主谋是猫：这张牌的气质是轻盈的、玩笑式的、会被一声猫叫打断的。若把"偷窃"写成人的恶意，会压坏"午后喧闹"的那一点甜；而猫的捣乱恰好是魔术师的另一面 —— **台面上的道具都是真的，只有台上那位（自称）客人是假的**。

## 四 角色设定（6 枚棋子）

| 棋子 | 身份 | 执器 / 四质 | 一句话 | 与牌的联系 |
|---|---|---|---|---|
| **V** | 魔法师（受害者） | 一点光 / 第五质·空无 | 「万物皆备于我。」 | 牌的题眼；无面、月相为脸；温柔而寂寞 |
| **A** | 司茶女仆 | 杯盏 / 水 | 「茶凉之前，请让我把这一杯续完。」 | 茶水 = 意志的流动 |
| **B** | 午后诗人 | 羽毛笔 / 风 | 「我要为这个午后写一个不一样的结尾。」 | "令人怀念的午后喧闹"的记录者 |
| **C** | 甜点师 | 餐刀 / 火 | 「第七块蛋糕，要切给谁呢？」 | 餐刀与甜点圆盘 = 四质里的火与土 |
| **D** | 钟表匠 | 圆盘（怀表）/ 土 | 「三点还很长，足够我们再坐一会儿。」 | 无限符号 = 停摆的怀表；把"现实"钉在午后 |
| **E** | 猫「墨」（盗窃者/主谋） | 无器 / 空无里的一点黑 | 「喵。」（它从不回答问题） | 魔术师的杂耍者原型；说谎的那张牌 |

**猫的形象**：黑猫，胸口一小块白，像溅上的一滴牛奶；尾巴尖是白的，像蘸了糖霜；左耳缺一小角（被牌框的荆棘勾的）。它走路不出声，所以没人知道它什么时候离开过软垫 —— 除了它留在长桌上的**梅花爪印**，和桌布下露出的一截白尾巴尖。

**魔法师的形象**：高挑、深紫燕尾服、白手套；脸是**一枚月相**（新月→满月），随剧情推进变化；袖口和领口有银色卡框纹样。他不拿任何器物 —— 因为"万物皆备于我"。他唯一的动作是往茶里加糖，而糖罐现在是空的：光就是从糖罐里被拨走的。

## 五 空间：月谕茶室（棋盘 = 卡面俯视图）

**棋盘就是这张牌的画心**：外圈是银白尖拱卡框，下方是横幅（写着关卡名），四角是菱形星饰；6×6 的格子是牌面插画的俯视切片。

| 区域 | 场景 | 四质 | 陈设 |
|---|---|---|---|
| **R1 长桌厅** | 牌面正中那张长桌的所在 | 调和之地 | 长桌、椅子、茶壶、羽毛笔、糖罐（空） |
| **R2 月窗廊** | 牌面上方/右侧的窗与月 | 空 / 月 | 月窗、玫瑰与荆棘 |
| **R3 茶点间** | 牌面下方的甜点与餐刀 | 火 / 土 | 蛋糕架、餐刀、甜点圆盘 |
| **R4 玫瑰廊** | 牌面边缘的玫瑰藤与猫的软垫 | 风 / 土 | 软垫、怀表、玫瑰藤 |

> 最终几何、门与家具格位以 `案件003-布局图.png` 与 `case_003` 数据为准。

**美术基调**（详见 `案件003-美术设计.md`）：银白蚀刻卡框 × 深紫夜空 × 玫瑰洋红 × 奶油金；卡面质感 = 水粉/版画混合；一切边缘带一点"画出来的笔触"，像一张被翻旧了的占卜牌。

## 六 玩法：这一关要玩家做什么

1. **摆座次**：六位宾客各就各位（每行每列一人）。受害者魔法师的位置也要摆。
2. **读牌**：六张线索卡 = 六张从牌堆抽出的牌，每张牌上有一个人说的话（或"月谕圣牌"显现的占卜）。
3. **发现谎言**：全部为真时无解 ⇒ 有人说了假话；找出哪一张牌是假的。
4. **指认主谋**：谁偷走了「一点光」，以及它把光藏在了哪里（= 盗窃者所在的那一格）。

**教学点（进阶关）**：
- 复习：家具 / 行列 / 房间 / 门相邻。
- 新点：**"独处"的房间会说话** —— 受害者独处月窗廊这一事实，加上 R3（盗窃者在受害者相邻区域里无辜人数最多的那间），把嫌疑人收进长桌厅。
- 新点：**谎言不是靠提示漏的，是靠"牌与牌之间对不上"抓的** —— 猫的牌与占卜、与座次、与结构三处对不上。

## 七 结局

- **指认正确**：猫从桌布下探出头，尾巴一抖，一点光滚回茶壶上方。茶重新热了，玫瑰重新红了。魔法师没有生气，只是把空糖罐推到猫面前，说：
  > 「万物皆备于我 —— 除了你，墨。」
  卡面定格：五个人的剪影围坐，猫趴在桌下，一点光悬在茶壶上方。文本浮出卡牌最后一句：
  > 「那一个顷刻的欢笑与『魔法』，也不过是无尽空无中凝聚而成的一点光。」
- **指认错误**：茶凉，月光变暗，卡面从边缘开始褪成空白，只留下一行小字："再抽一次牌吧。"（可重来）
- **彩蛋**：每个房间藏一处猫的痕迹（梅花爪印、桌布下的尾巴尖、被拨到桌脚的糖罐、玫瑰藤上的一撮黑毛）；集齐后结算页多一句猫的独白。

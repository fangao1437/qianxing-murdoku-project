## 快速结论

- **7×7、7 枚棋子 A–F/V、7 张卡线索**；盗窃者 = 猫「墨」E；无同伙；唯一假话 = 第 5 张卡。
- 答案：A(1,2) · D(2,3) · **E(3,1)** · V(4,6) · F(5,4) · C(6,7) · B(7,5)。
- 三厅：R1 长桌厅（长桌 + 两侧 6 椅 + 红毯 + 桌面叠加层）/ R2 月窗廊（月窗 (3,6)(3,7)，V 独处）/ R3 后厅（玫瑰藤 (6,6)、软垫 (7,5)，诗人坐在上面）。
- 结构：V 独处 R2（k=1）；Adj(R2)={R1,R3}；inno(R1)=3 > inno(R3)=2 ⇒ 盗窃者必在 R1 长桌厅。
- 验证：validate_levels 格式/结构/假话 OK；design_solve 摆位唯一、盗窃者唯一（按 (摆位, thief) 去重 = 1）；独立复核通过。
- 线索卡：七张外观完全一致，**不设计正逆位区分、不做任何真假视觉标记**；假话只靠文案与座次矛盾推理。

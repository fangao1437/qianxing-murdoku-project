# 02 · 手搭流程（层表设计 → 规格 → 预览迭代）

> "手搭"= 像美术板绘一样，用官方基础形状一层层叠出家具；产物是 `TemplateSpec.layers`。
> 与 01 的关系：01 是"自动拆解"，02 是"人工/半自动修边与补充"；两者输出同一格式。

---

## 1 总流程（每件家具）

```
① 参考量测（长边占格/主色/部件比例）
② 部件拆解（哪几个大块/哪些边角/哪些细节）
③ 画布与层表（order 1..N 从下到上）
④ 写 JSON（TemplateSpec）
⑤ 预览对照（S3 渲染 89~108px/格，与原作并排）
⑥ 迭代（调尺寸/位置/颜色/层序）
⑦ 交 S4 写入器
```

### ① 参考量测（已实测，可直接用）

| 家具 | 长边占格 | 主色（采样） |
|---|---|---|
| 椅子 | 0.836 | 奶白 `#FEF7E4` + 棕金 `#D9C08A` + 描边 `#1F1A14` |
| 桌子 | 0.836 | 桌面 `#AD9C67`、桌沿 `#8C7F52`、黑线 `#1F1A14` |
| 书架 | 0.821 | 柜体 `#D0B0D9`、层板 `#E4CBE9`、书 `#A98BC0 / #B2DBEB`、框 `#1F1A14` |
| 植物 | 0.760 | 叶 `#79CFA1`、盆 `#FCA161`、暗叶 `#1E2A18` |
| 雕像 | 0.912 | 石身 `#9AA3B8`、暗部 `#2A2E3A`、亮部 `#C6CBDD`、底座 `#3C3C46` |

### ③ 画布

| 模板 | content 画布 | 模板根（编辑器侧） |
|---|---|---|
| 单格（chair/plant/statue/shelf/table.1/rug） | **108×108** | 150×150 |
| 横桌 `table.h2` / 横跨地毯 `rug.2` | **216×108** | 150×150 |
| 竖桌 `table.v2` / 竖跨地毯 `rug.3` | **108×216** | 150×150 |

> 108 是 **content 画布**，不是模板根；写错（根 108）会导致"预览有、试玩没有"。

## 2 分层范式（从下到上，通用）

```
L1..Ln   阴影/大块底色（大面积铺底，决定轮廓）
Ln+1..   内面（浅色，向内缩 2~3px，留出深色轮廓边）
...      边角/描边修正（黑框、分隔线、桌沿、台阶边）
...      不同色细节（高光带、衣褶、书脊、叶脉）
```

**例子（当前基线）**

| 家具 | 层数 | 结构 |
|---|---|---|
| 桌子 table.1 | 11 | 阴影 → 左右腿(黑框+内芯) → 桌面黑框(107102) → 桌面面 → 顶带 → 黑分隔线 → 桌沿 → 黑底边 |
| 桌子 table.h2 | 11 | 同上，宽向 ×2、腿 dx±56 |
| 桌子 table.v2 | 11 | 同上，高向拉长、腿在底部 dx±26 |
| 书架 shelf | 24 | 阴影 → 黑框 → 柜体 → 顶板 → 内部黑框 → 3 层×5 本书 → 3 层板 → 底座 |
| 地毯 rug | 3 | 外框 108² → 内面 82.1² → 内线 64.8²（居中） |
| 地毯 rug.2 | 3 | 外框 216×108 → 内面 190.08×82.08 → 内线 172.8×64.8 |
| 地毯 rug.3 | 3 | 外框 108×216 → 内面 82×190 → 内线 64.8×172.8 |
| 雕像 statue | **381** | 原作图标压缩（见 01 §4；不手搭） |

**关键设计经验（都是返工换来的）**：
1. **底边/分隔线必须贴桌面底缘**，不能放 `dy=0`（否则黑线跑到桌面中间）；
2. **左右腿必须镜像**（写成 dx=±25.38、dy=40.5；曾把右腿写成 0,0 叠在中间）；
3. **书要横跨整个宽度**并站在层板上（曾 5 本书全挤左半边 ⇒ "书错位"）；
4. **雕像不要用少量大椭圆硬凑**（会变成雪人/花瓶）——平涂图标建议直接走 01 路线 B 压缩；
5. **半透明细节必须有实心底**（否则透格子底色，出现"空洞"）：
   - 拟合图元：用"每层不透明副本打底"（`art_v331_statue.json` 做法）；
   - 或直接压缩（`art_v332g_statue.json`，当前方案）。

## 3 层表字段（与 06 Schema 一致）

```jsonc
{
  "order": 1,               // 从下到上，1..N 连续
  "imageId": 100001,        // 只允许 100001/100002/100003/107102/106056
  "color": "0xFFAD9C67",    // 0xAARRGGBB
  "w": 76.5, "h": 66.5,     // 画布 px
  "dx": 0.0,                // 相对 content 中心，右正
  "dy_down": -11.0,         // 向下为正
  "y_up": 11.0,             // = -dy_down（写盘工具用）
  "rotDeg": 0.0             // 可选，默认 0
}
```

**硬规则**：
- 轴对齐优先（旋转只给需要斜度的有机形状/衣褶）；旋转细线在真机容易糊；
- 同色相邻尽量合并/少层；**互不重叠的块顺序无关**（压缩产物就靠这个）；
- 所有几何层 alpha=FF；阴影用 106056 + 0x66/0x9A 透明度；
- 单模板层数上限：无硬限制（模板层不占控件组 1000 预算），但每层在 `.gil` 里是 1 条记录 ×2（源/母本），注意文件体积与导入时间。

## 4 规格生成方式（三种，产物同格式）

1. **从 `lua/furn_art.lua` 提取**（手搭层基线）：
   ```
   node art/tools/gen-layers.mjs --furn-art=<主项目>/lua/furn_art.lua --out=out/spec.json --check
   ```
   （工具仓库 `qianxing-murdoku-tool/art/`；`--check` 与仓库内 spec 逐层比对，容差 0.011px）
2. **人工写 JSON**：小件/试验件直接写 `TemplateSpec`；
3. **拆解产物转换**：01 的拟合记录 → `export_rich_templates.py`；图标压缩 → `compress_statue.py` / `finalize_statue_v332g.py`。

## 5 预览迭代（S3）

```bash
# 工具仓库（零依赖）：
node art/tools/check-spec.mjs                       # 规格自检（模板集合/层数/颜色/尺寸/层序）
node art/tools/render-preview.mjs --layout=... --spec=... --out=out/preview.svg
# 或项目内 Python 预览（更接近真机像素）：
python _work/art-tools/render_preview.py ...        # 棋盘 1600×900、格宽 89/108
```

**预览必须与真机同源**：
- 棋盘几何：画布 1600×900、棋盘框 584×584 @(608,138)、ruler 12、gap 4；
- 格宽 5×5=108，6×6≈89；渲染时按 `格宽/画布基准` 缩放；
- 对照图建议三列：**旧版 / 新版 / 原作图标**，按真机格宽渲染（89px）。

**验收**：形体/比例/配色接近参考；跨格件连续；层级不盖头像/墙；地毯边框在整块外侧。

---

## 6 交付给写入器的内容

1. `TemplateSpec`（每模板：名字、画布、层数、层列表）；
2. 目标模板 GUID（由写入器从基准 `.gil` 查或用 `things` 引用回读）；
3. 每模板**画布尺寸** → 同时更新运行时 `furn_tpl_canvas` 配置（108/216/108×216）；
4. 对照图与回执（给真机验收用）。

# 04 · 运行时约定（插件与游戏侧的接口）

> 写入器只管写盘；**能不能正确显示由运行时（客户端 Lua + 适配层）决定**。
> 本节是"写入器/美术必须知道的运行时行为"，也是验收判据来源。

---

## 1 实例化流程（脚本侧参考实现）

```
关卡进入
 → cells 建好（cell 模板实例）
 → face：每格 content 底部实例化 cell.face（命名 face，Sibling 0）
 → furn_level 属性到达
 → 从 root/things 读模板映射（referencedPrefabIndex → 归一化键）
 → 对每格 wants（furn_tpl / furn_span / furn_offset）：
      game.InstantiateClientUIControl(模板源 GUID, 格子 content)
      命名 furni.<cell>
      SetSizeDelta(cell*span)
      SetAnchoredPosition(offset * cell)   # y 取负
      内容缩放 = 实例尺寸/模板画布 × 全局/分类系数（SetLocalScale）
      SetSiblingIndex(rug=1 / 其它=2)
```

**属性到达顺序无关**：`furn_tpl / furn_span / furn_offset / furn_level` 任意顺序都要收敛
（参考实现：恒受理+缓存+补造；span/offset 后到会销毁重建；0.5s resync 兜底，见 07 坑 11）。

---

## 2 节点与层级

```
board
 └─ cell.r.c
      └─ content
           ├─ face                     ← 每格实例化 cell.face 模板（Sibling 0）
           ├─ furni.cell.r.c|<kind>    ← 地毯 Sibling 1；其它家具 Sibling 2
           └─ hint / wall.* / door.* / note / portrait / x   ← 覆盖层（在家具之上）
```

- 层序 = **地板 → 地毯 → 家具 → 墙/门/笔记/头像**；
- 家具不许盖头像/墙；地毯不许盖家具；
- `SetSiblingIndex` 越界会静默失败 ⇒ 写完回读 `GetSiblingIndex()` 打日志。

---

## 3 尺寸与缩放（真机口径）

```
实例尺寸 = 格子像素 × span            # 5×5=108px/格，6×6≈89px/格
内容缩放 = (实例宽/模板画布宽, 实例高/模板画布高) × 全局系数 × 分类系数
全局系数 cfg.furn_scale = 0.93
分类系数 cfg.furn_scale_by_kind = { rug=0.82, rug_2=0.82, rug_3=0.82, statue=0.85 }
按轴系数 cfg.furn_scale_axis_by_kind = { rug_2={x=0.93,y=0.762}, rug_3={x=0.762,y=0.93} }
```
- 画布登记：`cfg.furn_tpl_canvas = { rug_2={216,108}, rug_3={108,216}, table_h2={216,108}, table_v2={108,216} }`（缺省 108×108）；
- 实现用 `SetLocalScale(x,y,1)`（官方 API；**没有** `SetScale`），回退读 `localScaleX/Y` 字段；
- 格子尺寸优先取**布局 rects**（`self.rects[cell].w/h`），不要只信模板默认 `sizeDelta`（见 07 坑 10）。

---

## 4 跨格件（桌子/地毯）

- 锚点格 = **包围盒右下格**；
- `span = { r, c }`；`offsetCells = { dx: (c1+c2)/2 - anchor.c, dy: (r1+r2)/2 - anchor.r }`（单位=格，dy 向下）；
- 运行时 `SetAnchoredPosition(offset.dx * cellW, -offset.dy * cellH)`；
- 单格地毯 `furn.rug`；横跨 `furn.rug.2`；竖跨 `furn.rug.3`（依赖 `things` 里三个引用都在）；
- 横/竖桌同理 `table.h2` / `table.v2`（画布与 span 对应）。

---

## 5 切关与回收

- 切关：销毁上一关全部家具实例、清缓存（`furn_level=false` 或切关事件）；
- 缓存键 = `(cell_id, 模板键)` ⇒ 同一格可以既有地毯又有家具；
- face 每格常驻（随格子重建而重建），不随切关销毁；
- 属性先到/后到都能收敛，但**不要在未清缓存时重复造同键实例**。

## 6 调试日志（真机判读）

| 日志行 | 含义 |
|---|---|
| `[murdoku] ===== 构建标记 vNNN / 日期 / 说明 =====` | 版本核对（导入的是哪一版） |
| `[murdoku] 面层：cell=… 实例化 face（prefab=…，尺寸=…px）` | face 通道正常 |
| `[murdoku] 家具模板映射：things 找到=… 条目=N keys={…}` | things 引用读取正常 |
| `[murdoku] 家具模板：cell=… ← furn.xxx（prefab=…，格子=…px，父控件=content）` | 每件实例化成功（数量=件数） |
| `[murdoku] 家具层缩放：子层=N 缩放=0.824,0.824 成功=… 基值读不到=0` | 缩放通道正常 |
| `[murdoku] 家具模板缺映射：模板键=… → 归一化键=…` | 键不匹配（查 things 名字/cfg） |

> 判读顺序：先看构建标记 → 再看"家具模板"行数 → 最后看画面层级/尺寸。

---

## 7 插件化注意

1. 运行时约定（本节）属于**游戏侧实现**，插件只负责"按约定写盘 + 更新 cfg"；
2. 写入器新增模板时，**必须同时**更新 `things` 引用 + `furn_tpl_canvas` + 分类/按轴缩放系数（如需要），否则运行时会缩错/溢格；
3. 运行时行为若变化（如缩放从改容器改为 SetLocalScale），历史结论需以**最新脚本为准**（见 `lua/engine_adapter_qianxing.lua` 注释里的版本号）。

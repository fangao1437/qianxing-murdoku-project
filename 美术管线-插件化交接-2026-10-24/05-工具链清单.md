## 3 写入器（S4，工程仓 `qianxing-murdoku/tools/gil/`）

### 3.1 核心读写
| 工具 | 说明 |
|---|---|
| `gilread.mjs` | 读 `.gil`：`readGil` / `recordsOf` / `parseMsg` / `setChildList` / `setPair` … |
| `gilwrite.mjs` | 写 `.gil`（重编码 + 帧） |
| `roundtrip.mjs <gil>` | 读→写→读 **逐字节一致** 校验 |
| `probe_guid_collision.mjs <gil>` | 真撞号 / 自身 GUID 一致 |
| `diff_fields.mjs <a> <b>` | 两档字段级差异（写入器预计算对账） |
| `list_names.mjs <gil>` / `check_visible.mjs --list` | 名字/可见性清单 |
| `dump_rec.mjs <gil> <id>` | 单条记录 dump（#501/#502/#504/#505/#503…） |
| `records.mjs` / `inventory.mjs` | 记录统计 |

### 3.2 模板/引用写入（按轮生成脚本）
| 脚本 | 用途 |
|---|---|
| `gen_templates_524.mjs` / `gen_templates_526.mjs` | 在用户编辑器模板上补 content + 层（v9/v10） |
| `gen_rich_layers.mjs` | 拟合图元 → 三模板层（v11） |
| `gen_531.mjs` ~ `gen_551.mjs` | 每轮容器生成（桌子换代、书架、rug.3、雕像修缮…**最新是 gen_551**） |
| `rebuild_things.mjs` | 重建 `things` 引用控件 |
| `probe_ui_registry.mjs` | UI 注册表探针 |

### 3.3 脚本打包/嵌入（S5）
| 工具 | 说明 |
|---|---|
| `tools/bundle_client_script.lua` | 15 模块 → `dist/client_script.lua` |
| `tools/bump_build_marker.mjs --set=NNN --note="…"` | 版本标记 + BOM 检查 |
| `tools/lua53check/check.cjs dist/client_script.lua --run` | Lua 5.3 编译 + 顶层执行 |
| `tools/gil/embed_script.mjs --in= --out= --script= --expect-marker=vNNN` | 嵌入并校验三方标记链 |
| `tools/gil/out/probe_embedded_script.mjs <gil>` | 读回内嵌脚本（标记/字节数/与 dist 一致性） |

## 6 常用命令（cheat sheet）

```bash
# 规格自检 + 预览（工具仓）
cd qianxing-murdoku-tool
node art/tools/check-spec.mjs
node art/test/run.mjs --furn-art=../qianxing-murdoku/lua/furn_art.lua

# 写入器一轮（示例：按 gen_551 改）
cd qianxing-murdoku
node tools/gil/gen_551.mjs          # 产出容器 551-…-容器-v21.gil
node tools/gil/roundtrip.mjs 551-….gil
node tools/gil/probe_guid_collision.mjs 551-….gil

# 脚本链
node tools/bump_build_marker.mjs --set=332 --note="…"
lua tools/bundle_client_script.lua
node tools/lua53check/check.cjs dist/client_script.lua --run
node tools/gil/embed_script.mjs --in=551-….gil --out=552-一二关美术-v332.gil --expect-marker=v332

# 校验
node tools/gil/roundtrip.mjs 552-….gil
node tools/gil/probe_guid_collision.mjs 552-….gil
node tools/gil/out/probe_embedded_script.mjs 552-….gil
```

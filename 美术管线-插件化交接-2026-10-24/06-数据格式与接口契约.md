# 06 · 数据格式与接口契约（插件之间的唯一约定）

> 插件之间只交换本节定义的 JSON。所有结构带 `version`（当前 `1`），字段名不得随意改。
> 可执行校验骨架：`schemas/*.schema.json`（草案）；最小示例：`examples/*.json`。

---

## 0 通用约定

| 项 | 规则 |
|---|---|
| 编码 | UTF-8，无 BOM |
| 数字 | 浮点保留 2 位小数（尺寸/位置）；颜色/尺寸误差容差 0.011px |
| 颜色 | `0xAARRGGBB` 字符串（大写/小写不限，写入器统一大写） |
| 路径 | 相对工作区根；输出文件不得覆盖输入文件 |
| 失败 | 抛结构化错误：`{ "code": "...", "message": "...", "detail": {...} }`；不允许静默降级 |

## 1 `Layer`（层）

```jsonc
{
  "order": 1,              // 1..N，从下到上（非重叠块顺序无关）
  "imageId": 100001,       // 100001|100002|100003|107102|106056
  "color": "0xFFAD9C67",
  "w": 76.5, "h": 66.5,    // 画布 px
  "dx": 0.0,               // 相对 content 中心，右正
  "dy_down": -11.0,        // 向下为正
  "y_up": 11.0,            // = -dy_down（写盘口径）
  "rotDeg": 0.0            // 可选，默认 0
}
```

## 2 `TemplateSpec`

```jsonc
{
  "template": "furn.statue",       // 唯一名字（things 引用同名）
  "kind": "statue",                // chair|plant|statue|table|carpet|shelf
  "variant": "1",                  // "1"|"h2"|"v2"
  "sizePx": [108, 108],            // content 画布
  "layerCount": 381,
  "layers": [ /* Layer[] */ ]
}
```

## 3 `ArtSpecSet`（S1/S2 的输出，S3/S4 的输入）

```jsonc
{
  "version": 1,
  "name": "v332",
  "source": { "mode": "compress", "icon": "statue__secret-lab.png", "quantize": 8, "size": [56,91], "std": 2, "mae": 0.03 },
  "cellTemplatePx": 108,
  "templates": {
    "furn.statue": { /* TemplateSpec */ }
  }
}
```

`source.mode`：`fit`（拟合图元）| `compress`（图标压缩）| `hand`（手搭）。

## 4 `Layout`（关卡布局，S3 输入）

```jsonc
{
  "version": 1,
  "name": "demo-4x4",
  "rows": 4, "cols": 4,
  "frame": { "x": 608, "y": 138, "size": 584, "ruler": 12, "gap": 4 },
  "rooms": [ { "id": 0, "name": "大屋", "color": "#D9CDB4" } ],
  "cells": ["0000","0000","0011","0011"],
  "objects": [
    { "name": "长桌", "kind": "table", "cells": [[1,1],[1,2]] },
    { "name": "地毯", "kind": "carpet", "cells": [[3,1],[4,1]] }
  ]
}
```

`kind ∈ {table, chair, plant, statue, shelf, carpet}`；table/carpet 按 4 邻接合并。

## 5 `WriterJob`（S4 输入）与 `WriterReport`（输出）

```jsonc
{
  "version": 1,
  "base": "qianxing-murdoku/547-一二关美术-容器-v19.gil",
  "out": "qianxing-murdoku/551-一二关美术-容器-v21.gil",
  "ops": [
    { "op": "replace_template_layers", "template": "furn.statue", "sizePx": [108,108], "layers": [ /* Layer[] */ ] },
    { "op": "set_things_ref", "name": "furn.rug.3", "prefab": 1073749968 },
    { "op": "set_family", "template": "furn.rug.3", "family": 94 }
  ],
  "expect": { "records": 1499, "templates": { "furn.statue": 103 } }
}
```

支持的 `op`（首版必须实现）：
| op | 语义 |
|---|---|
| `replace_template_layers` | 替换模板（源+母本两份 content）的层列表；删旧层、建新层、重排子列表 |
| `set_canvas` | 改 content 画布（sizePx/几何） |
| `set_things_ref` | 在 `root/things` 下确保名为 `name` 的引用控件，引用值=`prefab`（模板**源** GUID） |
| `set_family` | 设置模板族号（新建模板时） |

```jsonc
// WriterReport
{
  "version": 1,
  "out": "…/551-…-容器-v21.gil",
  "records": { "before": 1491, "after": 2047 },
  "templates": { "furn.statue": { "layers": 381, "motherLayers": 381 } },
  "gates": {
    "reread": true, "roundtrip": true, "deterministic": true, "idempotent": true,
    "collision": 0, "thingsRefs": { "count": 10, "missing": [] }
  },
  "handwritten": ["762 new layer records", "2 content child lists", "statue content sizePx unchanged"],
  "samples": [ { "template": "furn.statue", "layer": 1, "readBack": { "imageId": 100001, "color": "0xFF0F0D0F", "w": 9, "h": 2, "pos": [2.5, -44.5] } } ]
}
```

## 6 `EmbedJob`（S5）

```jsonc
{
  "version": 1,
  "container": "qianxing-murdoku/551-…-容器-v21.gil",
  "script": "qianxing-murdoku/dist/client_script.lua",
  "out": "qianxing-murdoku/552-一二关美术-v332.gil",
  "expectMarker": "v332"
}
```

输出 `EmbedReport`：`{ embeddedBytes, marker, distMarker, match: true, sha256 }`；
**失败即抛错**，不产出文件。

## 7 `ValidationReport`（S3/S6 共用）

```jsonc
{
  "version": 1,
  "ok": true,
  "checks": [
    { "id": "spec.imageIds", "ok": true },
    { "id": "spec.colors", "ok": true },
    { "id": "spec.layersNonEmpty", "ok": true },
    { "id": "preview.generated", "ok": true }
  ],
  "screenshots": ["_work/art-work/v332g-statue-compress.png"]
}
```

## 8 插件函数签名（建议，JS/Python 任选其一实现）

```ts
// S1
decompose(input: { iconPng: string; kind: string; size?: [number, number]; mode: "fit"|"compress"; params?: object })
  : ArtSpecSet

// S2
buildSpec(input: { measurements: object; parts: object[]; canvas: [number, number] })
  : ArtSpecSet

// S3
preview(input: ArtSpecSet | { spec: string; layout: string })
  : { svg?: string; png?: string; report: ValidationReport }

// S4
write(input: WriterJob): WriterReport

// S5
embed(input: EmbedJob): EmbedReport

// 共用
validate(input: ArtSpecSet | WriterJob | { gil: string }): ValidationReport
```

**错误码约定**：
| code | 含义 |
|---|---|
| `E_SPEC_INVALID` | 规格字段非法（imageId/颜色/尺寸/层序） |
| `E_BASE_MISMATCH` | `expect` 与基准档实际不符（记录数/层数） |
| `E_GIL_WRITE` | 写入/重编码失败（四闸之一失败） |
| `E_COLLISION` | 真撞号 |
| `E_MARKER` | 标记链不一致 |
| `E_EDITOR_LOSS` | 编辑器往返后层丢失（见 07 坑 1，需人工介入） |

## 9 版本与兼容

- 结构 `version` 变化 = 破坏性变更，插件必须拒绝旧版本并提示迁移；
- 同一 `version` 内只允许**新增可选字段**；
- 数据基准变化（如档号 547→551）由 `base` 字段显式指定，不隐式取最新。

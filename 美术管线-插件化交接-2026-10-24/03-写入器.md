# 03 · 写入器（Spec → .gil 模板/引用 → 出档）

> 写入器 = 把 `TemplateSpec` 写进 `.gil` 的**模板内容**，并维护 `things` 引用控件；
> 输出"容器存档"，再由 S5 嵌入脚本得到可导入游戏的最终档。
> 参考实现：`qianxing-murdoku/tools/gil/gen_5xx.mjs`（每轮一个脚本）+ `gilread.mjs` / `gilwrite.mjs`。

---

## 1 `.gil` 记录结构（写入器需要认识的全部字段）

`.gil` = protobuf 风格记录流；每条记录：

| 字段 | 含义 | 备注 |
|---|---|---|
| `#501` (varint) | 记录 id（GUID） | 1073xxxxxx 段；全局唯一（真撞号=0） |
| `#502` (msg) | 状态块 | 子块 `#501=1`（id）等；模板对还要 `#502[3]/#13`、`#502[4]/#14` |
| `#504` (varint) | 父记录 id | 模板源=null，母本=1073741844（模板容器） |
| `#505` (msg, 可多个) | 组件槽 | 控件类型/名字/几何/引用值都挂这里 |
| `#503` (bytes) | 子列表 | 变长 varint 序列 = 子记录 id（顺序=兄弟顺序） |
| `#505/#12/#501` text | 控件名字 | 层/内容容器/引用控件的名字 |
| `#505/#14/#501` float | 几何 | 模板对里源/母本的 `#14` 互相指 |
| `#508/#3` float | **旋转角（度）** | 图片控件的旋转；同静态烘焙口径 |

> 探针：`node tools/gil/dump_rec.mjs <gil> <id>` 看任意记录；`node tools/gil/inspect_gil.mjs <gil>` 看全局。

## 2 模板对（必备形态）

每件家具/地毯 = **两条模板记录 + 两份 content**：

### 2.1 源（Source）
- `#504` 父 = **null**（顶层）；
- 组件块 `#502[4]` 里 `#14` = 母本 id；
- 族号（family）= 模板组编号（85~92 依次给 chair/plant/statue/table.1/table.h2/table.v2/shelf/rug/rug.2/rug.3）；
- 名字 = `furn.xxx`（`things` 引用与脚本按名字/引用值匹配）。

### 2.2 母本（Mother）
- `#504` 父 = **1073741844**（编辑器模板容器）；
- 组件块 `#502[3]` 里 `#13` = 源 id；
- 名字与源相同。

### 2.3 content（源/母本各一份）
- 父 = 对应模板源/母本；
- 组件类型 = **容器节点**（`content`，与 `cell.1.1/content` 同型，工具里以 cell content 为模板克隆）；
- 画布 = 108×108 / 216×108 / 108×216（`#505` 几何与 `sizeDelta`）；
- 子列表 = N 个**图片控件**（层），顺序 = `order`。

### 2.4 层记录（图片控件）
| JSON 字段 | 写入点 | 说明 |
|---|---|---|
| `imageId` | `#505` 图片组件的图元 id | 100001/100002/100003/107102/106056 |
| `color` | `#505` imageColor（0xAARRGGBB） | 原样写，含 alpha |
| `w/h` | `#505/#14` + sizeDelta | 画布 px |
| `dx/dy_down` | anchoredPosition = `(dx, -dy_down)` | 相对 content 中心，y 向上 |
| `rotDeg` | `#508/#3` | 度；0 可省略 |
| `order` | 子列表顺序（`#503`） | 1..N |

**硬性要求**：层的记录必须**克隆自"编辑器认的图片控件"**（拿基准存档里现成的层记录做模板，改字段），不要凭空构造；
否则编辑器可能不认（见 07 坑 1）。

## 3 `things` 引用控件（运行时映射）

- 容器：`root/things`（隐藏容器，名字固定）；
- 每个模板 1 个**模板引用控件**：
  - 组件槽 **66/89**（引用控件形态，不是模板的 68/91）；
  - 引用叶子：`/505(66/89)/#503/#77/#501` = **模板【源】GUID**（不是母本！）；
  - 名字 = `furn.xxx`（与模板名一致，逗号/点号会被脚本归一化）；
  - 父 = `root/things`；
- 运行时脚本：读 `referencedPrefabIndex` → 归一化键（`furn.table.h2`→`table_h2`）→ 实例化。
- 多格地毯需要 `furn.rug.2` / `furn.rug.3` 两个引用（与 `furn.rug` 并存）。

## 4 GUID / 族号 / 记录预算

| 项 | 规则 |
|---|---|
| id 段 | 1073000000~1074200000（`gilread.ID_LO/ID_HI`） |
| 新增记录 | 从基准 `.gil` 的 `maxId+1` 起连续分配；**不得撞号**（`probe_guid_collision.mjs` 校验） |
| 族号（family） | 每个模板组一个：85 chair / 86 plant / 87 statue / 88 table.1 / 89 table.h2 / 90 table.v2 / 91 shelf / 92 rug / 93 rug.2 / 94 rug.3（以实际档为准，新增前查 `list_names`） |
| 控件组 1000 上限 | 只算**一个界面控件组画布内**的控件（我们的 root 树），模板内层**不计** |
| 模板 2000 上限 | 按模板个数；每模板根+content+层记录都写在 `.gil` 文件里（体积/导入时间自估） |
| 屏上 10000 上限 | 运行时展开的实例+层都要算；单只雕像 381 层实例占 381 个控件（第二关仅 1 只，安全） |

## 5 写入器事务契约（插件 S4 必须遵守）

**输入**：`WriterJob`（见 06 §5）
```jsonc
{
  "version": 1,
  "base": "qianxing-murdoku/547-一二关美术-容器-v19.gil",
  "ops": [
    { "op": "replace_template_layers", "template": "furn.statue", "sizePx": [108,108], "layers": [ ... ] },
    { "op": "set_things_ref", "name": "furn.rug.3", "prefab": 1073749968 }
  ],
  "expect": { "records": 1499, "templates": { "furn.statue": 103 } }
}
```

**必须做到**：
1. **原地重算**：删除旧层记录 + 新增层记录 ×2（源/母本） + 更新两份 content 的 `#503` 子列表；
2. **不覆盖基准档**（输出新文件）；
3. **四闸**（缺一不可）：
   - ① 重读记录数 == 计算值；
   - ② roundtrip：读→写→读**逐字节一致**；
   - ③ 确定性：同一输入连跑两次 SHA 相同；
   - ④ 幂等：已满足的 job 再跑一次 = 原样复制、SHA 不变；
4. 额外闸门：`probe_guid_collision` 真撞号 0、`list_names` 模板/引用计数对、`diff_fields` 与预计算差异一致；
5. **报告**（`WriterReport`）：记录数变化、每模板层数回读、抽样层字段、手写记录清单（编辑器可能不认的部分）。

参考实现：`tools/gil/gen_549.mjs`（雕像 381 层那次，最典型）。

## 6 脚本嵌入链（S5）

写入器只产出"容器"（结构），脚本由 S5 嵌入：

```
lua/*.lua + lua/entry_client_script.lua
   ↓ tools/bundle_client_script.lua      # 15 个模块 → dist/client_script.lua
   ↓ tools/bump_build_marker.mjs --set=NNN --note="…"   # 三方标记链：source=dist=embedded
   ↓ tools/lua53check/check.cjs dist/client_script.lua --run
   ↓ tools/gil/embed_script.mjs --in=container.gil --out=final.gil --expect-marker=vNNN
```

**规则**：
- 版本标记是"独立事实"：`source`（entry 里）== `dist` == `.gil` 内嵌，三处一致才算成功；
- bump 会检查 **BOM**（有 BOM 会炸 Lua 加载）；
- 标记行的 note **不能包含"画布"二字**（`tests/entry_smoke.lua` 用 `has("画布")` 定位画布尺寸日志，会被 marker 抢走）；
- 最终档命名：`5xx-一二关美术-vNNN.gil`，回执写 `docs/回执-xxx-vNNN.md`。

## 7 写入器常见事务失败与处理

| 现象 | 原因 | 处理 |
|---|---|---|
| 层数回读不对 | 只改了一份 content（源或母本） | 两份都改；逐份回读 |
| 真撞号 >0 | 新记录 id 与现有重叠 | 从 `maxId+1` 分配，跑 `probe_guid_collision` |
| roundtrip 不一致 | msg 重编码长度/字段顺序问题 | 用 `gilread → gilwrite` 官方路径，别手改字节 |
| 幂等失败 | 每次重新分配 id | 先检测"已满足"→ 原样复制 |
| 编辑器打开后层没了 | 手写层/模板编辑器不认（见 07 坑 1） | 模板必须编辑器建；层内容需用"打开→保存→导出"副本验证 |

# 第三、四关 v11 几何关联复核

## 修改范围

保持两关房间、门、答案站位、盗窃者身份不变，不修改现行规则。第三关只改A/C卡，家具7格不变；第四关A卡合并同室椅子条件，D卡承接原A的左右关系，删除E不在椅子旁边，在(1,1)加1格桌子，总家具5→6格。其余卡原样。V均为单条。

| 提供者 | 第三关C | 第四关B |
|---|---|---|
| A | 我在B上方、C左方 | D在我所在房间的椅子上 |
| B | A在植物旁边 | 我在E右方 |
| C | 我与A在同一房间 | 只有我在地毯上 |
| D | 我在桌子旁边 | A在我左方 |
| E | D在我上方 | B比D靠下1行 |
| V | B在植物旁边 | A在我下方 |

“上下左右”只比较相应轴，不要求同行/列。“旁边”为同室四邻。A的第四关卡是“D坐椅子 AND D/A同室”合取，整卡假只要求至少一项假。两关都不提前告知真假，不能先把第三关全真或第四关有假话当成已知。

## 四层验收

| 项目 | 第三关 | 第四关 |
|---|---|---|
| 规则合法性 | 通过，家具、连通房间、门、行列、区域人数及严格真假均合法 | 同左 |
| 推理可达性 | 有完整有限身份分支证书；正确身份后几何交集与人数收口可直接传播 | 有完整有限身份分支证书；正确身份后保留一次试位及具体矛盾 |
| 完整摆位唯一性 | 仅1种 | 仅1种 |
| 盗窃者身份唯一性 | 仅A | 仅E |
| 最终口供真假 | 六卡全真，为结果 | 仅E假，为结果 |
| 单卡能否定位任何人 | 均不能 | 均不能 |
| 附加位置试位深度 | 0 | 1 |

两个独立实现都从6!×6!=518400种带人物的行列合法摆法开始，家具过滤后再计算全部身份；求得最终结果后才与冻结答案比较。深度采用每卡独立广义弧一致传播、全局行列排他与区域规则的约束表，加单人位置试探。它不是所有人类解法的绝对下界。根据用户最新补充，必要猜测是可选方法，不是设计铁律；本版第三关不再宣称比教程多一层必要猜测。

## 第三关：多方几何约束形成精确位置

1. 从未知身份逐一测试A–E，使用其余真卡、区域规则计算上述摘卡候选。A假设的两个候选仅A/B对换；B/C假设都使其本人单格却卡真；D/E无解。故A成立且必须真，六卡全真是结果。这是一条有限可核查路径，不声称它是玩家最轻量的顺序。
2. B卡与V卡使A/B占据同室植物四邻两格(1,2)、(2,1)，暂未定朝向。
3. A说在B上方，故A=(1,2)、B=(2,1)。A还在C左方，只能知道C列>2，没有数字距离。
4. C说与A同室。R1中排除第1/2行及第1/2列，再结合C位于A右侧，只有(3,3)：第3行第4列已越墙，第4行R1只保留左侧两列。于是C=(3,3)。原关系A在C上方2行、B在C左侧2列，此时才成为结果。
5. D的桌旁候选结合已占行列仅余(5,4)、(6,5)。D在E上方，不能处于末行，因此D=(5,4)，E只能在第6行。
6. 未占行列留下两种尾盘：E(6,5)/V(4,6)，或E(6,6)/V(4,5)。两种都满足全部真卡。
7. 第一种：V在R2，门相邻R1无辜B/C共2人，R3无辜D共1人，R1严格最多，A可成立。第二种：E转入R3，R1与R3无辜人数均2，违反不许并列，因此排除。最终E=(6,5)、V=(4,6)。

### 多方参与的反例证书

这些数量仅用家具可站性与行列排他，不先用身份，也不先用旧答案筛选：

| 使用信息 | 摆法数 | 不满足旧两项精确关系的摆法 |
|---|---:|---:|
| 仅A新卡 | 70416 | 68748 |
| 仅C新卡 | 55488 | 54636 |
| A+C两张新卡 | 16236 | 15972 |
| 全部卡真 | 2 | 0 |
| 去A，其他卡真 | 4 | 2 |
| 去C，其他卡真 | 64 | 62 |

因此A、C任一卡都不是直接改写旧距离，两卡合用也不能直接读出旧关系；植物、房间轮廓与行列排他不可省。此证书说明几何关系恢复需要多来源，不等于声称每张卡在完整严格身份问题中都不可删除。

## 第四关：合并卡与家具封堵

### 家具的真实作用

将A改成D坐椅且A/D同室、D承接A在D左方，删掉E椅旁否定条件而不加家具时，E摘卡有两种本人位置：(1,1)、(3,1)。必须说真话，但E卡在这两个摆法都假，因此整个设计没有合法严格解。

在(1,1)放不可站的桌子，封掉第一支，E摘卡仅剩(3,1)，本人格数变为1，于是必须说假话，且最终盘B=(1,2)、D=(6,5)确实不满足B比D靠下1行。正确答案的E本来就不在椅子旁，但这已不是题面条件。

加桌子的备选点还有(3,2)，本版选(1,1)，避免在主要人物中段新增阻挡。未宣称所有可能家具类型下的全局最少，仅在本次候选中1格即可，0格失败。

### 有限可达路径

1. 从身份未知分A–E测试：B/C/D无候选；A摘卡有6盘、本人3格，却无一满足本人合并卡，排除；E摘卡一盘、本人1格、卡假，成立。
2. 正确身份与严格真假确定后，传播得到：A=(3,1)/(5,4)，C=(2,3)，D在两把椅子之一，E=(3,1)/(5,4)，V仍有少数候选，未一口气定位。
3. 试A=(3,1)。逐卡传播、区域计数与行列排他迫使D=(6,5)、E=(5,4)、B=(4,6)、V=(1,2)，但A与D不同室，违反A真卡，矛盾。证书记录到卡A已无可支持的完整摆法，而非仅凭预设答案排除。
4. 因而A=(5,4)。A/D同室与D坐椅使D=(6,5)；A在V下方及区域人数进一步收缩，B、E、V最终确定，得到B=(1,2)、E=(3,1)、V=(4,6)。

## 冻结答案

第三关：A(1,2)、B(2,1)、C(3,3)、D(5,4)、E(6,5)、V(4,6)，盗窃者A。

第四关：A(5,4)、B(1,2)、C(2,3)、D(6,5)、E(3,1)、V(4,6)，盗窃者E。

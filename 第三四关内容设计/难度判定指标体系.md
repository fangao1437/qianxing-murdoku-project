## 2. 「深度」专题

历史上三个东西都叫过「深度」，混用会得出错误结论。

### 2.1 三种口径

| 版本 | 字段 | 含义 | 硬闸门 |
|---|---|---|:---:|
| v8 / v11 | `position_assumption_depth` | **位置试位深度** | ✅ 当时 |
| v12 / v13 / v14 | `gac_depth` | **广义弧一致传播深度** | ✅ 当时 |
| **v16** | 无 | **不重算、不作硬闸门** | ❌ |

### 2.2 精确定义（引自 `两关难度复核_v8.md`）

> 每张完整卡为独立约束表，区域门/人数为独立约束表，行列排他内置；
> 反复删去在单个约束表中没有支持的候选格（广义弧一致传播）。
> 停滞后任选一个人物分割其所有候选格，递归传播，按**最坏分支的最大嵌套深度**计数；
> 遍历所有可选人物得到该操作集中的**最小深度**。

- `0` = 纯演绎，无需试位；`1` = 需一次试位。
- 身份与该身份的真假条件**先给定**，再测额外位置试探深度；身份判断的枚举成本另列。
- **边界**：证明的是「声明的操作集内 0→1 提升」，不是「所有人类解法都必然要假设」。
  合并多张线索或更强的整体计数可能绕过试位，这一更强命题从未被证明。

### 2.3 为什么 v16 把深度降级

v16 改用「全线索候选格」口径：`S` 不摘卡，`P(h)` 是全线索盘面中盗窃者的位置集合。
旧深度算法建立在「摘本人口供 + 预先套身份人数规则」之上——该候选定义已作废。
因此 `当前设计与验证口径_v16.md` 明确：

> GAC 深度不作为本次新验收的硬闸门，历史深度记录不冒充重算结果。

深度值仍保留在历史 JSON 里供追溯，但**不再重新计算**、不进 PASS、不写进当前验收结论。

## 3. 同名字段的定义漂移（最易出错）

| 字段 | v12–v14 定义 | v16 定义 | 为什么不能直接比 |
|---|---|---|---|
| `all_true_boards` | 六张卡全部为真的摆法数 | `S` = 全部卡面为真 ∧ 全部通用线索为真 ∧ 基础摆位规则，**不摘卡、不含人数规则** | v14 第 3 关 = 2，v16 第 3 关 = 3 |
| `thief_own_positions` | 摘掉盗窃者卡后其本人的候选格数 | `P(h)` = `S` 中盗窃者的不同位置数 | v14 第 5 关 = 1，v16 第 5 关 = 0 |
| `contradiction_min_subset` | 按卡面全当真求最小矛盾子集 | v16 不再计算 | 不得把历史矛盾子集写进 v16 结论 |
| `unique_thieves` / `identity_hypotheses` | 断言身份唯一 | `identity_uniqueness_claimed=False` | 旧报告写死 `unique_thieves=1` 已作废 |

**唯一摆位 ≠ 唯一盗窃者身份。** v16 只要求预设身份下摆位唯一；教学关其他身份结果
只记录、不用假话分支否决教学设计。

## 6. 当前口径下的难度分档（建议，非已实现闸门）

v16 不以 GAC 深度分档。按现有效指标，可用下面四个维度描述难度：

| 维度 | 低 → 高 |
|---|---|
| 真相形态 | 教学全真（不启用假话反事实） → 条件说谎（需真/假分支判定） |
| `P(h)` | ≥2（多解待人数规则收口，教学） → ≤1（全线索已收窄） |
| 语言负载 | 每卡一句、0 方位距离、0 否定 → 复合卡、否定、通用线索 |
| 辅助强度 | 浅蓝提示格多（辅助强） → 少（辅助弱） |

**注意**：这只是描述性分档建议，尚未写进 `verify_v16.py` 的硬闸门；
`difficulty_band` 是设计数据里的说明字段，不参与 PASS 判定。
按此观察，第 3/6 关（教学全真）低于第 5/7 关（条件说谎）；
第 7 关因额外通用线索与 19 项检查，结构最复杂。

## 7. 引用规范（三条禁令）

1. **不得**拿 v11–v14 的 `PASS` 或 `gac_depth` 宣称 v16 当前通过。
2. **不得**把历史 GAC 深度值冒充 v16 重算结果；v16 没有深度字段。
3. **不得**在 v16 结论里写「盗窃者身份唯一」——`identity_uniqueness_claimed=False`。

引用历史值时须标注版本与口径，例如：
「v14 第 7 关 `gac_depth=1`（旧口径，已作废，不参与当前验收）」。

另外：`verify_v14.py` 的旧验收入口已停止执行并委托 `verify_v16.py`；
旧版本数据会被拒绝。两个底层 `Model.audit` 保留历史算法用于追溯，但明确作废并发出警告。

## 9. 边界

本指标体系只覆盖**离线内容设计与枚举验证**口径。枚举唯一不等于人类解法优美；
历史 GAC 深度只针对当时声明的传播/试位操作集，不是所有解法的绝对下界；
未导入游戏、未做实机渲染或玩家试玩，也不宣称难度已获玩家侧确认。

`difficulty_metrics.json` 由 `_work/_murdoku-opt34-20261113/build_difficulty_metrics.py`
从各版本 `verification_*.json` 与 `current_design_v16.json` 抽取生成，可重复构建。

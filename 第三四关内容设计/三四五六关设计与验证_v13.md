## 1. 四关规格

### 第 3 关 · 新家具 + Easy 与 Medium 之间（无谎）

**家具 9 格**：桌子 `(6,4) (4,4) (2,3)`、植物 `(1,1)`、椅子 `(2,1) (2,4)`、
地毯 `(3,2) (3,3) (4,2)` —— 即 v11 全量 + 三格地毯 + 第三张桌。

| 提供者 | 谓词 | 卡面 | 真值 |
|---|---|---|---|
| A | `B在植物旁边` | B在植物旁边 | 真 |
| B | `A在植物旁边` | A在植物旁边 | 真 |
| C | `只有C在地毯上` | 只有我在地毯上 | 真 |
| D | `A在B上方` + `A在C左方` | A在B上方、A在C左方 | 真 |
| E | `D在E上方` | D在我上方 | 真 |
| V | `D在桌子旁边` | D在桌子旁边 | 真 |

三格地毯作为**可站立面**进入 `只有我在地毯上`；三张桌进入 `D在桌子旁边`。
六卡同真仍有 2 盘，"无谎"由身份分支正向推出；最后一步由区域无辜人数严格最多收口。

### 第 4 关 · 双格地毯 ×2 + r2 视觉均匀（一谎）

**家具 10 格**：桌子 `(1,1)`、植物 `(5,6) (2,6)`、书架 `(2,5)`、
椅子 `(1,2) (6,5)`、地毯 `(2,2) (2,3) (6,1) (6,2)`。

| 提供者 | 谓词 | 卡面 | 真值 |
|---|---|---|---|
| A | `D在椅子上` | D在椅子上 | 真 |
| B | `V在植物旁边` | V在植物旁边 | 真 |
| C | `C在地毯上` | 我在地毯上 | 真 |
| D | `A在D上方` | A在我上方 | 真 |
| E | **`D在书架旁边`** | **D在书架旁边（本关唯一假话）** | **假** |
| V | `B在桌子旁边` | B在桌子旁边 | 真 |

最小矛盾子集 = **2**：`D在椅子上`（椅在 (1,2)/(6,5)）与 `D在书架旁边`（架在 (2,5)）
在几何上不能同真 → 玩家不必穷举即知必有假话。新增的 r2 书架/盆栽与双格地毯
都进入了线索，不是纯装饰。

### 第 5 关 · 降难度前的第4关派生（换 id + 门墙家具全改 + 深色视觉）

- **人物分布格集合**与 v11 第4关完全相同 `{27,1,8,34,12,23}`，仅换 id：
  `A→C B→D C→E D→A E→B`（V 不动），卡片按"卡随人走"重排，盗窃者随之变为 **B**。
- **墙**：`(3,4)` 从 R2 划入 R3；**门**：首扇 `(2,3)-(2,4)` → `(1,3)-(1,4)`。
  门格不与任何不可站家具重叠，四间房均连通，所有门跨不同区域。
- **家具 7 格**：桌子 `(4,4)`、植物 `(1,1)`、书架 `(2,5)`、椅子 `(1,2) (6,5)`、地毯 `(2,3) (6,2)`。
- **线索**保留 v11 第4关原貌（换 id 后）：精确数字距离 `D比A靠下1行`、
  复合自述 `A在椅子上、我与A在同一房间`、`只有我在地毯上` 等。
- **难度**：GAC 深度 **1**（保留降难度前的一次试位），身份分支 2，矛盾子集 3，
  六张卡全部非冗余。

| 提供者 | 卡面 | 真值 |
|---|---|---|
| A | C在我左方 | 真 |
| B | **D比A靠下1行（本关唯一假话）** | **假** |
| C | A在椅子上、我与A在同一房间 | 真 |
| D | 我在B右方 | 真 |
| E | 只有我在地毯上 | 真 |
| V | C在我下方 | 真 |

### 第 6 关 · 与第3关同几何、Medium 加难、与第4关同款视觉

**几何逐字段等于第3关**（房间 / 门 / 人物分布 / 九格家具 / 目标站位），
只替换线索与视觉方案。v12 旧线索在这套新家具下仍成立，故同一盘面可承载更高难度。

| 提供者 | 谓词 | 卡面 | 真值 |
|---|---|---|---|
| A | `B与C在同一房间` | B与C在同一房间 | 真 |
| B | **`C比V靠上2行`** | **C比V靠上2行（本关唯一假话）** | **假** |
| C | `A在B上方` + `A在C左方` | A在B上方、A在我左方 | 真 |
| D | `B在植物旁边` | B在植物旁边 | 真 |
| E | `D在桌子旁边` + `D不在植物旁边` | D在桌子旁边、D不在植物旁边 | 真 |
| V | `D在E上方` | D在E上方 | 真 |

**加难口径**（相对第3关）：从"六卡全真"升级为"一谎"；引入精确数字距离
（官网 Medium 标志）；两张复合卡（第3关 1 张、第4关 0 张）；一条否定句；
身份分支 3→4、摘卡候选盘合计 66→120；谎言最小矛盾子集 **6**（第4关仅 2），
玩家无法靠两卡识破，必须多源交叉。仍保持纯演绎 GAC 深度 0。

## 4. 通用验证引擎与闸门

`murdoku_engine.py` 相对 v12 的验证器做了两处推广，供新增家具类型使用：

1. **家具类型可配置**：`OBJECT_REGISTRY` 登记 9 类（官网 id / 官网名 / 可站 /
   关数 / 差异化命名 / 本地美术是否已支持），自动按 `occupiable` 决定不可站格
   与「在 X 上」候选；`validate_geometry` 断言家具不重叠、答案格未被不可站家具占用、
   四间房连通、所有门跨不同区域。
2. **区域结构可配置**：`room` / `doors` 由关卡数据给出，区域规则掩码按门邻接重算。

两套独立实现交叉验证：位集 `Model` 与 numpy 全集 `independent`。
`verify_v13.py` 可独立复跑，逐关检查：

- 冻结项：第3关 = v11 第3关的房间/门/人物/身份；第4关 = v12 第4关；
  第5关人物格集合 = v11 第4关但 id 已换且门墙家具已改；第6关几何 = 第3关逐字段相同。
- 家具规格：第3关三桌三毯；第4关两处双格地毯且同房间、r2 有书架。
- 语言闸门：3/4 关禁精确数字距离、全局计数、内部 `R1/R2` 与行列编号；
  5/6 关允许数字距离；所有关卡面无内部编号。
- 四层验收：规则合法性 / 有限可复核推理可达 / 完整摆位唯一 / 盗窃者身份唯一。
- 严格真假：0 格不成立 / 1 格必须假 / ≥2 格必须真；复合卡合取判真；不预告真假。
- 删卡严格非冗余（摘掉任一真卡后完整严格题不再唯一/正确）。
- GAC 深度：3/4/6 = 0（纯演绎），5 = 1（保留降难度前的一次试位）。
- 谎言可察性：第3关六卡可同真；第4关两卡矛盾；第6关矛盾子集 ≥3。
- 视觉方案：第6关主题 key 必须等于第4关。

复跑结果（`python verify_v13.py`）：**四关全部 PASS**。

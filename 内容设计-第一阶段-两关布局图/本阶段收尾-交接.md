### ① 同伙规则废止（`structure_report`）

删掉的两条：

```
⑪ 受害者所在区域人数 k >= 2  ⇒ 盗窃者必然有且只有一个同伙
⑫ 同伙必须与盗窃者待在同一个区域
```

**现在的语义**：

- `k` 取任何值都**不再**要求同伙；
- 关卡在 `roles` 里声明了 `accomplice`，那个角色才存在（旧关卡 `case_003` / `demo_selftest` 不受影响）；
- 同伙**不再**被要求与盗窃者同区；
- **R3 保持不变**（盗窃者所在区域 = 受害者相邻区域里无辜人数最多的那个）。

另外 `view().structure.must_have_accomplice` 由 `k >= 2` 改成**恒为 false**（保留字段名，界面/存档在读它）。

**实测**（`lua check_accomplice_rule.lua`，跑在旧 `case_002` 上）：

```
case_002：区域数=3，受害者区域 k=2，声明同伙=C
① 声明同伙 C 且同区   ⇒ OK
② k=2 且【无同伙】   ⇒ ★ 合法（新规则生效）
④ view(): must_have_accomplice=false  has_accomplice=true  k=2
```

### ② 补两条线索类型

引擎原有的类型里**没有**这两条，而两关定稿需要它们（★ 只补**类型**，线索**内容**由编辑器 row 区填）：

| 类型 | 含义 | 用在哪 |
|---|---|---|
| `nobody_on_object` | 没有任何人站在 X 上（X 可多格，如"地毯"） | 第二关通用线索 |
| `below_in_other_room` | a 在 b 下方的不同区域中 | 可独立使用 |
| `alone_and_below_in_other_room` | who 独自一人 **且** a 在 b 下方的不同区域中（一句复合陈述） | 第二关 v 的那句话 |

★ 为什么 v 的那句做成**一条复合类型**：假话判据是按**整条**算的，拆成两条会把"一句假话"的粒度弄糊。

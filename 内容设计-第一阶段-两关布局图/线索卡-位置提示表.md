# 两关线索卡 · 位置提示表

> 用途：给线索卡配"原作那样"的提示 —— 点一张卡，就把**这条线索允许这个人出现的位置**在地图上高亮出来。
> 图：`案件001-线索卡高亮提示.png` ／ `案件002-线索卡高亮提示.png`
> 数据由脚本从**真实关卡文件**算出（`lua clue_hint.lua`），不是手画的。

---

## 一 什么线索给位置提示、什么不给

★ **本版规则（按你的要求）**：

| 线索里有没有**直接位置信息** | 给不给提示 | 例子 |
|---|---|---|
| 有：**某件家具** | 给 —— 高亮那件家具的格子，或它四邻的可站格 | 「在桌子旁」「站在椅子上」「站在地毯上」 |
| 有：**某一行／某一列** | 给 —— 高亮那一整行／列的可站格 | 「在第 5 列」 |
| **没有**：只在讲**人和人的关系**，或**几个人** | **不给** | 「我独自一人」「在谁下方」「有两人在椅子上」里的"两人"这类计数 |

⇒ 本案里**不做位置提示**的只有两条，都在第二关：

- **卡 d**：`e 在 a 的上方` —— 纯人对人关系
- **卡 v**：`我独自一人，c 在我下方的不同区域中` —— "独自一人" ＋ "在我下方"

★ 顺带说明：`在谁上方／下方`在本作里还有个结构性问题 —— 它要求**同一列**，
　 而本工程开了「每列恰好一人」，所以两人**永远不可能同列** ⇒ 这类线索在本作里**恒为假**。
　 第二关的 d 正是利用这一点当假话，但它也因此**根本没法给出位置提示**（给出来就会剧透）。

## 二 通用规则（以后新加线索照这个来）

| 线索类型 | 高亮什么 |
|---|---|
| `on_object` / `only_on_object` / `one_on_object` / `n_on_object` / `nobody_on_object` | **该家具的格子本身** |
| `beside_object` / `only_beside` / `not_beside_object` | **该家具四邻**、同区域、且**可站人**的格 |
| `in_col` | 那一列的**可站格** |
| `in_row` | 那一行的**可站格** |
| `above` / `below` / `offset` / `col_offset` / `row_offset` | ★ **不做位置提示**（人对人关系） |
| `alone` / `alone_in_room` / `alone_with` / `with_only` | ★ **不做位置提示**（讲的是"和谁在一起"，不是"在哪一格"） |
| `different_room` / `room_has` / `room_size_hint` | ★ **不做位置提示**（区域级） |
| `not_role` / `is_role` | ★ **不做位置提示**（讲身份，不讲位置） |

## 三 案件 001 · 夜盗独行（5×5，三个区域）

### 3.1 说话顺序（已按你的要求改）

| 卡序 | 现在由谁来说 | 这句线索原本属于谁 |
|---|---|---|
| 卡 1 | **A 值班保安** | 原 v |
| 卡 2 | **B 前台姑娘** | 原 d |
| 卡 3 | **C 夜班清洁工** | 原 a |
| 卡 4 | **D 旧识古董商** | 原 c |
| 卡 5 | **V 收藏家** | 原 b |

★ **线索内容一个字没改，只换了说话人** ⇒ 摆位、R3、模糊规则、唯一解**全部不受影响**
　（推理只依赖"有哪些事实"，不依赖"谁说的"）。
　 之前实测过：五条线索 → 2 个摆位 → R3 只放行 1 个 → 模糊规则判定盗窃者 = D ⇒ 唯一解。

## 五 给界面/row 区用的时候

1. **高亮的是"可站人的格"**：家具占了但不可站的格（桌子/植物/书架/雕塑）不出现在高亮里；
   椅子/地毯是可站的，所以它们**可以**被高亮（例如卡 4 的椅子、卡 3 的地毯）。
2. **不要高亮答案摆位**：上面图里的白圈字母只是**给你对答案用的**，正式提示里不该出现。
3. 高亮建议用**一层半透明底色**（图中用的 `#FDE68A`），不要盖住家具图标 —— 玩家要能同时看到"这格是什么家具"。
4. 两张图里的小棋盘与坐标（`(行,列)`）就是 row 区填内容时的对照表。
5. ★ 第二关的 d 是**假话**：如果提示系统对"假线索"也一视同仁地不亮格子，玩家就分不出哪条是假的 ✓
   —— 这正好符合"假话要靠推理抓、不靠提示漏"的原则。
